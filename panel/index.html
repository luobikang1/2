使用说明

什么是 TUIC？

TUIC 是基于 QUIC 协议的代理工具，具有低延迟、抗丢包、支持 UDP 的优势，适合网络环境不稳定的场景。

如何使用？

  1. 部署本面板到 Cloudflare Pages（或其他平台）
  2. 将你的域名绑定到项目
  3. 在面板中输入域名，一键生成节点
  4. 将生成的订阅链接或二维码导入客户端（如 NekoBox、Clash、Sing-Box）

密码保护

部署时设置环境变量 PANEL_PASS（或在 js/app.js 中修改 PANEL_PASSWORD），面板将要求输入密码才能访问。也可通过 URL 参数 ?pass=xxx 自动解锁。留空则不启用密码。

推荐客户端

  • Android: NekoBox, sing-box
  • iOS: Stash, Shadowrocket
  • Windows: NekoRay, Clash Verge
  • macOS: Clash Verge, sing-box

部署指南

Cloudflare Pages

推荐 — 免费、全球 CDN、自动 HTTPS

  1. Fork 本仓库到你的 GitHub
  2. Cloudflare Dashboard → Pages → 连接 GitHub
  3. 构建命令留空，输出目录填 panel
  4. （可选）环境变量添加 PANEL_PASS 设置访问密码

Vercel

一键导入 GitHub 仓库部署

  1. Import Git Repository → 选择本仓库
  2. Root Directory 设为 panel
  3. Framework Preset 选 Other，直接部署

Netlify

拖拽上传或连接仓库

  1. 拖拽 panel/ 文件夹到 Netlify Drop
  2. 或连接 GitHub，Publish directory 填 panel

GitHub Pages

免费静态托管

  1. Settings → Pages → Source → GitHub Actions
  2. 或设置 Branch: main, folder: /panel

Docker

容器化部署，可配合反向代理

docker run -d -p 8080:80 \
  -v $(pwd)/panel:/usr/share/nginx/html:ro \
  nginx:alpine

手动部署

纯静态文件，上传到任何 Web 服务器即可

git clone https://github.com/luobikang1/2.git
cd 2/panel
# 上传至你的服务器 /var/www/html
