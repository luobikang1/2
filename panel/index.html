使用说明

支持的协议

  • VLESS — 轻量高效，Cloudflare Workers 首选，支持 WebSocket + TLS
  • VMess — V2Ray 经典协议，广泛客户端支持
  • Trojan — 伪装 HTTPS 流量，简单高效
  • Hysteria2 — 基于 QUIC，极速低延迟
  • TUIC — QUIC 代理，抗丢包优秀

如何使用？

  1. 部署本面板到支持的平台
  2. 绑定域名到项目
  3. 选择协议，输入域名，一键生成
  4. 导入客户端（NekoBox / Clash / sing-box / Shadowrocket）

登录验证

设置环境变量 LOGIN_UUID 和 LOGIN_DOMAIN，访问面板时需输入对应的 UUID 和域名才能进入。留空则无需登录。

部署指南

Cloudflare Pages

推荐 — 免费、全球 CDN、自动 HTTPS

  1. Fork 仓库 → Cloudflare Pages → 连接 GitHub
  2. 输出目录: panel
  3. （可选）环境变量 LOGIN_UUID + LOGIN_DOMAIN 启用登录

Vercel

  1. Import Repo → Root Directory: panel
  2. Framework: Other → Deploy

Netlify / GitHub Pages

  1. Publish directory: panel

Docker

docker run -d -p 8080:80 \
  -v ./panel:/usr/share/nginx/html:ro \
  nginx:alpine
